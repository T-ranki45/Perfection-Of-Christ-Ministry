Use this page as your steady point of access before service.

Communication Flow

The admin team controls access for registered workers. If your number changes or access stops working, contact the church admin so they can update your record.

  • New phone number: ask the admin to update your worker record.
  • Code not received: request a resend from the login page.
  • Access removed: only the admin can restore it.
